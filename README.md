# Serene

A calm, private companion for your mental wellbeing. Track your mood and habits—nothing leaves your computer.

## About Serene

Serene is designed to help you understand yourself better, one day at a time. It's a gentle mirror that shows you patterns in your mood and habits without noise, pressure, or judgment.

### What You Can Do

- **🧘 Track Mood** - Rate your mood and mental state on a soft 0-10 scale
- **🎯 Build Habits** - Create your own set of positive and negative habits to track
- **📊 View Patterns** - See smooth graphs revealing how your mood and habits move together
- **📱 Monthly Overview** - Explore a full calendar with daily summaries and built-in analysis
- **🔒 100% Private** - Nothing is shared. Your data lives only on your device
- **⚙️ Customizable** - Lock with gesture or password, export/import backups

## Requirements

- Windows 10 or later (x64), or a Chromebook with Chrome
- No account required

## Installation

### Windows

1. Download `Serene-Windows.zip`
2. Extract `SereneSetup.exe`
3. Run the installer — choose the install folder and whether to add a desktop shortcut
4. Launch Serene from the Start Menu or desktop shortcut
5. Optionally lock the app with slide, password, or a 4-digit code in Settings

### Chromebook

1. Download `Serene-Chromebook.zip` (GitHub release or the site mirror)
2. Unzip the folder in Files
3. Open `index.html` with Chrome
4. Optional: install the page as an app from the Chrome menu

## Files & Folder Structure

- `index.html` - Main website homepage
- `404.html` - Custom 404 error page
- `icons/` - Favicon and app icons
- `assets/` - Logo and additional assets
