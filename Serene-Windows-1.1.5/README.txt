Serene v1.1.5 — Windows
=======================

WHAT IS SERENE
Serene is a calm, private desktop app for tracking your habits, mood and
mental state. Everything is stored locally on your PC. No accounts, no
cloud, no tracking.

WHAT'S NEW IN 1.1.5
- Minimize to tray: new setting under Settings → Minimize to tray. When on,
  closing or minimizing the window keeps Serene running as an icon in the
  Windows system tray. Click the tray icon to reopen; right‑click it to quit.
- Themed scrollbars: every scrollable surface (Today, Monthly, Graphs,
  Settings, dropdowns) now uses the glass accent scrollbar instead of the
  default Windows one, so the whole app matches the theme end to end.

INSTALL
1. Run "SereneSetup.exe".
2. Pick an install directory when asked.
3. Optionally tick "Desktop Shortcut".
4. Launch Serene from the Start Menu or Desktop.

PORTABLE
The "Serene-win32-x64" folder is the portable build — run "Serene.exe"
directly, no install needed. Note: for Windows notifications to appear
reliably, install via the setup and launch from the Start Menu shortcut.

UNINSTALL
Use "Add or remove programs" in Windows Settings, or run
"Uninstall.exe" inside the install folder.
